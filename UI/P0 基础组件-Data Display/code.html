Tree 规范状态机定义

1
展开/收起过渡: 三角图标 90° 旋转，动效耗时 180ms ease-in-out，禁止卡顿闪烁。
2
节点三态继承: 子项全选中 -> 父项Checked；部分选中 -> 父项Indeterminate（水平横杠标示）；子项全部未选 -> 父项Unchecked。
3
拖拽排序与插槽 (Drag & Drop): 目标节点上下方出现 2px 高亮蓝线及原点定位器，若移入节点内则触发节点背景蓝染。
Indent: 24px/Level Connector: 1px dotted rgba(0,0,0,0.12)
