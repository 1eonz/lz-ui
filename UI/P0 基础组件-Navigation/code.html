样式与语义交互要点:

  • 级联延迟防抖 (Mouse Leave Delay): 设定 120ms 缓冲三角走廊，防止用户斜向划入二级菜单时发生失焦闪烁。
  • 危险操作色系隔离: 终结性破坏操作固定使用 --lx-color-error，前置分隔线必须保留 4px 外边距。
  • 无障碍键位支持: 按上下键焦点线性轮询，按右键展开子菜单，按左键返回父级。

Menu 导航菜单体系 (Vertical, Sider & Horizontal)

覆盖三种企业级主流形态：垂直手风琴、极简折叠侧边栏（224px ⇋ 64px 带悬浮 Tooltip 菜单）、顶部横向菜单。

垂直菜单交互指标:

• 激活指示条 (Pill Indicator): 左侧锚定 3px 宽平滑圆角矩形，底色与图标高亮联动。

• 手风琴展开动效: 高度采用 CSS grid-template-rows: 0fr -> 1fr 实现无闪烁插值展开。

• 收起形态 (64px): 文字自动隐藏，Hover 图标时触发右侧浮动气泡（Popover Menu）。

accessibility_new 无障碍键盘流 (A11y Standards)

Tab / Shift+Tab 在顶级导航项之间线性跳动，不进入禁用态节点。
Arrow Keys Tabs 与 Menu 内使用方向键循环导航，激活项保持焦点轮廓（2px focus-visible）。
Enter / Space 触发展开 Dropdown 下拉菜单或切换当前激活 Tab。
Escape 立即收起当前任意打开的多层级级联菜单，并将焦点归还至触发器按钮。
