lx-ui Design Tokens & Base Foundations

面向企业级中后台 ERP / CRM 系统的底层设计基线。通过严格的 3 层 Token 映射架构（Global Primitive → Semantic → Component），确保统一的对比度无障碍性与高密度数据处理能力。

verified WCAG 2.2 AA Compliant
Prefix: --lx-*
L1. Primitive Tokens palette
全局物理色板 & 标量 --lx-color-blue-500: #1677FF; 不含业务语意，仅作为色彩、字阶、尺寸常量库。
L2. Semantic Tokens auto_mode
语义层 & 状态绑定 --lx-theme-primary: var(--lx-color-blue-500); 自适应 Light / Dark 主题及六大品牌预设的上下文切换。
L3. Component Tokens widgets
组件级抽象与作用域 --lx-btn-primary-bg: var(--lx-theme-primary); 直接作用于 Button、ProTable、SearchForm 等控件。

05 / Radii & Elevation

三重视觉风格预设 (Business, Soft, Glass)

圆角、投影、景深与模糊度的层次化组合
1. Business 商务稳重 Radius: 4px

低标高、克制阴影。采用紧凑的 4px 圆角与纯净的表面区分，减少多余视觉噪音，专注于巨量企业数据分析。

Elevation Tokens: --lx-radius-base: 4px; --lx-shadow-card: 0 1px 3px rgba(0,0,0,0.05);
2. Soft 轻盈现代 Radius: 8px

环境光漫反射与平滑层次。8px 适度圆角搭配平滑多层 Ambient Shadows，界面通透富有亲和力。

Elevation Tokens: --lx-radius-base: 8px; --lx-shadow-card: 0 4px 16px rgba(0,0,0,0.06);
3. Glass 玻璃液态 Radius: 16px

半透明磨砂介质与微内发光。12px/16px 大圆角配合 backdrop-filter: blur(16px)，用于仪表盘高光卡片。

Elevation Tokens: --lx-radius-base: 16px; --lx-backdrop-blur: blur(16px);
06 / Motion & Interaction

动画与交互过渡规范 (Animation Tokens)

微交互与状态反馈

按钮悬停、激活轻微回弹、Check/Radio 勾选状态瞬时变化。使用标准的 cubic-bezier(0, 0, 0.2, 1) ease-out。
