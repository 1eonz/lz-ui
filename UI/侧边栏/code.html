STRUCTURE & STATES 标准垂直侧栏状态机与 8pt 排版模数

层级树深度递归与清晰活跃指示

垂直层级树是企业级管理系统最稳固的心智模型。lx-ui 采用严格的 缩进模数：一级 pl-4 (16px), 二级 pl-8 (32px), 三级 pl-12 (48px)，杜绝由于多级深层导致文字挤压换行的问题。

Active 活跃态

背景应用 bg-primary/10，文字加粗，左侧绝对定位渲染 w-[3px] rounded-r-full 胶囊主色条。

Hover 悬停微光 mouse

鼠标悬停时平滑渐变至 bg-surface-container-low，左侧图标轻微加深，过渡曲线 200ms cubic-bezier。

180° 旋转箭头 sync

折叠/展开父菜单项时，右侧指示箭头以中心为轴顺滑旋转 180°，子菜单容器以 CSS 补间高度柔和收展。

宽度模数: Desktop 240px | Compact 208px ARIA: role="tree" aria-expanded="true"

从“目录翻找时代”到“极速直达时代”

大型企业 SaaS 系统中常包含多达数百个功能入口，层级嵌套甚至达到 4-6 级。命令式侧栏将入口聚拢为单次搜索直达，支持全拼与拼音首字母检索（例如输入 “dz” 直接命中 “跨境供应链对账中心”），同时沉淀精确到具体单据 ID 的历史足迹。

touch_app 单手零脱离

键入搜索词后，通过键盘 ↑ ↓ 切换焦点，按 Enter 触发瞬时路由重定向。

memory 高频记忆沉淀

根据用户近 7 天访问频度自动更新【常用快捷工作流】，并为每个单据打上时间相对位移标尺。

filter_alt 多维范围限定

支持输入特定前缀（如 `@order`、`#docs`、`$finance`）将搜索范围快速约束至指定业务子域。

推荐键盘快捷键映射: window.addEventListener('keydown', (e) => { if(e.metaKey && e.key === 'k') focusCmd(); }) Accessible ARIA: role="combobox" aria-autocomplete="list"
