Flex 弹性布局引擎 (Flex Container & Flex Item)

一维轴向排版标准，内置 6 种主轴对齐、5 种交叉轴对齐、三阶标准化间隙 (gap) 与子项弹性伸缩契约。

元素在空间充足时按权重放大，在空间狭窄时等比收缩，中后台搜索栏与标题栏最常用形态。

flex: "none" (绝对尺寸固定)

锁定元素的原始宽高 (`0 0 auto`)，通常用于操作按钮组、头像、标签图标等不可变几何实体。

order: number (视觉序列解耦)

在响应式场景下无需改变 DOM 结构，即可通过 order 参数重排操作列与信息块的展示顺序。

1
语义化 Landmark 角色标记 (Semantic Landmarks)

全局骨架必须严格绑定语义属性：Header 声明 role="banner"，侧边栏声明 role="navigation"，主内容区声明 role="main"，页脚声明 role="contentinfo"，保障读屏软件快速跳转。

2
焦点可见性与键盘触发 (Focus Ring & Keyboard Ops)

侧栏折叠按钮 (Trigger) 必须支持 Tab 键聚焦并具备 outline: 2px solid var(--lx-color-primary) 高亮轮廓；支持 Enter / Space 物理键盘切换。

3
200% 页面级无损缩放 (Reflow & Non-Horizontal Scroll)

在浏览器 200% 视图缩放或移动端视口下，PageContainer 自动降级为单列纵向流，吸底操作栏保持 safe-area-inset-bottom 避让，严禁产生破坏性横向双滚动条。
