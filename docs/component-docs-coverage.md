## 本批场景范围

1. 通用组件：Button 的类型/尺寸/禁用/异步操作；Icon 的来源/名称/旋转/降级；Typography 的层级/省略/复制/状态；Space 的间距/方向/折行/分隔；Divider 的方向/文本/间距。
2. 基础表单：Checkbox、Switch、Radio 的受控与禁用；Select 的单选/多选/搜索/空与加载/公开ref；InputNumber 的范围/精度/stringMode/格式；DatePicker/DateRangePicker 的受控/范围/禁用；FormItem 的校验/帮助/反馈/布尔与上传值；Upload 的本地选择/受控列表/限制/移除及显式请求边界。
3. DynamicForm 专项：最小schema、受控回填、条件字段、异步选项失败重试、自定义registry、实例submit/reset。业务演示保留，不能代替这些独立协议示例。
4. 后续组件随实现同批交付文档，不能先导出代码再长期留简短占位说明。

每页沿用 `docs/component-template.md`。可运行示例必须有标签、真实更新、稳定key和错误恢复；是否存在ref方法按实际公开类型记录。中文输入法、空值、宿主表单与主题上下文都必须在复审中核对。
