# ADR-0002：Ant Design 5 作为主线底座

## 状态

已接受

## 背景

旧参考项目使用 Ant Design 4，但新组件库面向 React 18/19，且需要 CSS Variables、主题切换、按需引入和持续维护。

## 选择

主包支持 Ant Design `>=5.24 <6`，`antd` 作为 peer dependency。原生组件从 `lx-ui/antd` 显式导出，增强组件从 `lx-ui` 导出。Ant Design 4 若有真实存量需求，另建 compat 包。

2026-09-30 收窄最低版本：早期 5.x 的 Alert/Progress 尚不提供当前封装承诺的 ref，宽泛的 `>=5` 会允许宿主安装不能满足公开契约的版本。5.24 与本仓开发依赖的最低版本一致，减少多个适配分支的维护成本。代价是 5.0–5.23 宿主需先升级；不增加全局 DOM 查询来弥补第三方缺失的 ref。类型、SSR 和实际消费验证分别记录于 `docs/compatibility.md`，提高 peer 下限本身不构成兼容性通过。

当前 `lx-ui/antd` 已显式转出首批迁移所需的 Button、Form、Input、Select、DatePicker、Checkbox、Radio、Switch、Upload、Empty 和 Skeleton；清单随 API 评审维护，不使用 `export *`。

## 优点

- 主题 token 和 React 18/19 生态更一致。
- 避免两套 API、日期依赖和样式机制同时进入主包。
- 迁移边界清晰，业务项目可以逐步用增强组件替换原生组件。

## 缺点

- 旧 antd 4 项目不能无成本直接安装新主包。
- 需要额外维护 `lx-ui/antd` 的导出清单和迁移文档。

## 重新评估条件

出现明确的 antd 4 存量迁移项目，并且重复需求达到多个项目时，再启动 `lx-ui-antd4-compat` 设计。
