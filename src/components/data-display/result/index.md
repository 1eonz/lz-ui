用于流程完成、失败或整页异常，状态、原因和恢复动作应一致。

## 基础用法：凭证提交成功

status="success" 配合 title 和 subTitle 表达已完成流程，extra 按需传按钮。错误和无权限场景应替换说明与恢复动作，而非只换图标颜色。

## 不同结果与恢复路径

error/500 本地重试恢复成功；403/404 只显示处理说明或返回本地列表，不授予权限、不展示受保护或不存在的凭证。

## 状态与受控协议

不同 status 为展示属性，不自带请求或权限策略。无法访问的记录禁止通过本地状态切换假装授权；恢复必须与标题、说明一致。

## API

从 `lx-ui` 根入口命名导入组件和对应类型。除扩展项外，其他属性沿用 [Ant Design 5 公开契约](https://ant.design/components/result/cn/)；默认行为随安装的 AntD 5 版本生效，下表列出常用参数。

| 属性       | 类型                    | 默认值 | 说明                            |
| ---------- | ----------------------- | ------ | ------------------------------- |
| `status`   | `ResultProps['status']` | `info` | 成功/错误/信息/警告/403/404/500 |
| `title`    | `ReactNode`             | `—`    | 标题                            |
| `subTitle` | `ReactNode`             | `—`    | 原因或下一步                    |
| `extra`    | `ReactNode`             | `—`    | 操作区                          |
| `icon`     | `ReactNode`             | `—`    | 自定义图标                      |
| `children` | `ReactNode`             | `—`    | 补充内容                        |

## 事件、Ref 与键盘

无内建重试或路由事件，extra 内按钮绑定宿主操作。ref 是 HTMLDivElement 外层；组件不移动焦点，动作卸载时宿主恢复焦点。

## 主题与密度

展开示例的“主题设置”可切换 light/dark、comfortable/compact、三种外观、六个品牌色与七套东方配色。品牌色选择会清除东方配色；选择东方配色后由 palettePreset 决定视觉色阶。Provider 禁用持久化，主题操作不重置当前业务状态。

主题仅改变外观与间距，不改变记录、权限或页码。需要显式尺寸时使用当前组件公开支持的尺寸参数；表格行高使用独立 token。长内容应允许换行，宽表格在容器内滚动。

## 边界与性能

权限由服务端验证，状态选择仅是本地视觉场景。失败不应伪装为成功，敏感信息不进入错误详情。行级错误放在相关字段附近。

## 设计与验证边界

示例对应 `UI/P0 基础组件-Data Display/` 的当前组件场景，所有恢复、失败与加载操作均为本地 React 状态，不发送网络请求。基础示例供观察单组件，交互示例说明宿主受控状态与恢复协议。静态检查不能替代明暗对比度、焦点、窄屏及 reduced motion 的独立浏览器验收。
