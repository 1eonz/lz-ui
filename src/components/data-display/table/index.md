# Table 表格

展示带列定义的数据，业务请求、权限和缓存由宿主处理。

## 基础用法：三列采购数据

columns 的 dataIndex 对应记录字段，render 负责单元格展示，dataSource 保存完整记录。rowKey 指向唯一 id；pagination={false} 关闭内建分页。两个普通滚动区示例都以命名、可聚焦的外层区域管理横向滚动；区域自身聚焦时，无修饰的左右方向键横向滚动，只有滚动位置实际改变时才取消浏览器默认行为。方向键不会在纯文本单元格间移动焦点，子控件按键与 Alt/Ctrl/Meta/Shift 组合键保留原行为。Chromium DOM 实测中，基础示例内部有带 `aria-hidden="true"`、`tabindex="-1"` 的辅助测量行，不形成顺序 Tab 停靠点；Chromium 与 Edge 均实测 Tab 可离开该区域。交互示例的复选框和行操作按钮仍按顺序可达。示例 Table 提供最小列宽且不启用固定列，避免内外双重滚动；固定列宿主配置见下文。

### 数据阅读与筛选

- **字段顺序：** 交互表格按设计稿展示订单编号、供应商、结算金额、履约进度和审批状态。订单编号单行显示，长供应商名称省略但保留完整文本与原生 `title`；进度使用带采购单名称的 `Progress` 展示本地固定比例，不代表实时对账结果。
- **排序与筛选：** 金额列支持鼠标和键盘 Enter 排序，表头保留焦点环、排序图标与 `aria-sort`；审批状态筛选支持全部、已审批、待审批，切换后回到第一页。“示例状态”原生 `details` 默认折叠，密度控件位于表格标题行。
- **横向阅读：** `tableLayout="fixed"` 与 856px 横向画布保留列宽，并由单一命名滚动区承载；聚焦普通滚动区后，无修饰的左右方向键横向滚动，滚动位置不变时保留浏览器默认行为。纯文本单元格不进入 Tab 顺序，方向键也不在单元格间移动焦点；子控件按键和带修饰键的组合仍交由自身处理。默认/large 非虚拟表格的舒适/紧凑基础行高为 48/36px，表头基础高度为 36px；粗指针下行高和单元格内距按至少 44px 的操作目标重算，紧凑纯文本行、含控件的短行和表头都会随之增高。长内容仍可换行并自然增高。

### 分页与选择

- **分页语义：** 示例由宿主负责分页，以命名 `nav`、原生按钮、`aria-current` 和页大小选择提供键盘与读屏语义。窄容器保留“第 X / Y 页 · 共 Z 条”的可见摘要，并显示上一页、页码选择和下一页；同时保留视觉隐藏的 `aria-live` 当前页播报。宽屏由页码状态和总数信息提供数据集规模语义。金额列关闭 AntD 默认英文悬浮说明。
- **分页边界：** AntD 内建分页可能把焦点放在缺少按钮语义的列表项上，因此本示例不使用内建分页；此选择不增加或改变 `Table` 的公开 API，业务项目可按需使用 AntD 分页或实现受控分页。筛选结果先整体排序，再切出当前页。
- **跨页选择：** 行复选框包含采购单编号，全选名称明确表示当前页。`preserveSelectedRowKeys` 会保留被筛选隐藏的已选订单；“已选订单”默认折叠，展开后可核对编号、供应商、审批状态与金额，并可取消全部选择。金额右对齐且使用等宽数字。

### 详情与恢复

- **行展开：** 展开按钮按订单编号命名，并通过 `aria-expanded` 报告状态；原生按钮保留 Tab、Enter 和 Space 操作，展开内容展示付款分期。
- **订单详情：** 详情是按订单编号命名的非模态区域，字段按采购信息、履约进度、审批与结算分组。打开后焦点进入详情标题，关闭后回到对应行操作；表格、已选列表、付款分期与详情的金额统一保留两位小数。
- **数据状态：** 排序、筛选、翻页、页大小和加载/失败/空状态切换会关闭详情。只有焦点随详情卸载而丢失时才回到表格标题；用户主动聚焦筛选或分页控件时保留其焦点。空状态和失败状态提供恢复操作。

## 宿主配置：固定选择、订单编号与操作列

固定列示例以 section 的 `ResizeObserver` 内容宽度判断布局：宽度至少 448px 时将选择列和订单编号固定在左侧、操作列固定在右侧。扣除两端固定列 302px 后，中间滚动区至少约 146px；该宽度随更宽容器增长，不代表采购员按钮初始可见。例如 930px 浏览器视口下文档 section 实测为 520px，采购员操作仍需横向滚动或按 Tab 才会进入视口。448px 阈值由 422px 列宽合计、粗指针目标、焦点轮廓和额外几何余量共同决定；较窄时关闭固定列，避免固定层遮住键盘焦点。使用容器宽度而非 window 断点，是因为文档侧栏和内容栏会改变示例实际可用空间；代价是窄容器不再固定两端列。`scroll.x` 明确覆盖所有列宽之和；示例不在 Table 外增加横向滚动容器，避免固定列以错误的可视边界定位。demo 在表格上方提示横向滚动，粗指针环境将主要操作目标扩大至项目触控尺寸 token。

“查看采购员”只反馈采购员姓名和所属部门。“查看订单详情”打开以订单编号命名的非模态区域，优先显示审批状态与采购金额，其后按订单信息、采购归属分组；组标题、分隔线、字段标签和值使用不同的字号、字重和间距层级，金额使用等宽数字。每组以语义化描述列表呈现标签和值。触发按钮同步 `aria-expanded` 与 `aria-controls`。打开或切换订单后焦点移到详情标题，关闭后回到最近触发该面板的行按钮。窄屏下仍先显示审批与金额，再纵向阅读其余分组；订单号保持完整并允许在编号前换行，极窄详情区域会将关闭操作移至标题下方，保证编号处于标题焦点区域内。长供应商名称可以换行。键盘用户可按 Tab 将操作按钮滚入可见区域并打开详情，以顺序阅读该行字段；这条路径没有给纯文本单元格增加方向键横向移动能力。示例面向 PC 中后台的宽表；手机视口用于验证横向滚动、触控命中尺寸和详情阅读，不代表建议把完整 1232px 表格作为移动端主要工作流。宿主若要求在手机上完成全字段浏览，应另行设计响应式列或卡片视图。

## 虚拟化：1000 条采购订单

虚拟化示例提供 1000 条唯一订单编号，以 `rowKey="id"` 保持行身份稳定，单行列值与显式 `scroll.y` 组成可测量的视口，并通过 `virtual` 显式启用虚拟滚动。示例提供一个可聚焦的命名区域：方向键逐条浏览，PageUp/PageDown 每次定位 10 条，Home/End 定位首末行，并通过公开 `LxTableRef.scrollTo` 定位虚拟行；鼠标滚轮或滚动条手动定位后，键盘导航会从当前滚动位置继续。带 Ctrl、Alt、Shift 或 Meta 的组合按键交由宿主和辅助技术处理。上述均为文档示例的交互，不会改变 `Table` 的键盘 API。虚拟化是 opt-in；动态行高、展开行、合并单元格及自定义 body 需要分别验证，不应直接套用此示例。

## 状态与受控协议

行复选框包含采购单编号的可访问名称，全选复选框标明当前页范围；跨页选择状态仍由宿主通过受控 `rowSelection` 管理。

loading、locale.emptyText 与宿主错误区域分别表达加载、空与失败。pagination、rowSelection 和 expandable 的 key 集可分别受控；不传受控字段时遵循 AntD 默认行为。页面级快速筛选与导出动作属于宿主工具栏，筛选宿主负责更新 `dataSource`，Table 不承载请求逻辑。交互示例用可键盘操作的 Select 演示本地快速筛选。`preserveSelectedRowKeys` 会保留当前 `dataSource` 未包含的已选 key，状态计数应按完整受控 key 集计算；宿主可提供清空选择操作。Ant Design 5.24 的内建列筛选入口无法通过 Tab 聚焦，且确认/重置操作显示英文默认文案，因此本示例暂不启用该交互；Table 仍透传公开列配置的 `filters`、`onFilter` 等筛选属性，并通过 `onChange` 返回筛选结果。升级 Ant Design 后，应重新验证内建筛选的键盘可达性和本地化，再评估是否在示例中使用。

## API

从 `lx-ui` 根入口命名导入组件和对应类型。除扩展项外，其他属性沿用 [Ant Design 5 公开契约](https://ant.design/components/table/cn/)；默认行为随安装的 AntD 5 版本生效，下表列出常用参数。

| 属性           | 类型                              | 默认值      | 说明         |
| -------------- | --------------------------------- | ----------- | ------------ |
| `dataSource`   | `T[]`                             | `—`         | 记录         |
| `columns`      | `LxTableColumns<T>`               | `—`         | 列定义       |
| `rowKey`       | `LxTableProps<T>['rowKey']`       | `key`       | 稳定唯一标识 |
| `pagination`   | `LxTableProps<T>['pagination']`   | `AntD 默认` | 分页配置     |
| `rowSelection` | `LxTableProps<T>['rowSelection']` | `—`         | 受控选择     |
| `expandable`   | `LxTableProps<T>['expandable']`   | `—`         | 展开配置     |
| `loading`      | `LxTableProps<T>['loading']`      | `false`     | 加载         |
| `scroll`       | `LxTableProps<T>['scroll']`       | `—`         | 滚动范围     |
| `virtual`      | `boolean`                         | `false`     | 虚拟滚动     |
| `locale`       | `LxTableProps<T>['locale']`       | `AntD 默认` | 空状态等     |

## 事件、Ref 与键盘

| 事件                            | 类型                                                                 | 触发时机             |
| ------------------------------- | -------------------------------------------------------------------- | -------------------- |
| onChange                        | `LxTableProps<T>['onChange']`                                        | 分页、筛选或排序变化 |
| rowSelection.onChange           | `NonNullable<LxTableProps<T>['rowSelection']>['onChange']`           | 选中项变化           |
| expandable.onExpandedRowsChange | `NonNullable<LxTableProps<T>['expandable']>['onExpandedRowsChange']` | 展开项变化           |

onChange(pagination, filters, sorter, extra) 返回下一配置，sorter 可为数组。rowSelection.onChange 返回 keys/records，onExpandedRowsChange 返回展开 keys。ref 是公开 LxTableRef 实例，不是 HTMLElement。

## 主题与密度

展开示例的“主题设置”可切换 light/dark、三种外观、六个品牌色与七套东方配色；Table 示例在通用设置中隐藏重复的密度开关，标题行的舒适 48px 基础 / 紧凑 36px 基础单选控件使用 `useLxTheme` 切换基础行高。粗指针下，默认/large 非虚拟表格会按 44px 操作目标重算表头、正文行高和单元格内距，因此紧凑基础行高实际至少为 44px，纯文本行也满足目标，舒适短行约为 48px；长内容和宿主内联单元格样式仍按内容或宿主设置生效。Table 适配层通过公开 `ConfigProvider.useConfig().componentSize` 解析宿主继承尺寸：`size` 显式传入时优先，解析为默认或 `large` 才应用 lx-ui 的表格行高类，`small`/`middle` 与虚拟行继续由宿主控制。其他演示仍保留通用密度开关。品牌色选择会清除东方配色；选择东方配色后由 palettePreset 决定视觉色阶。Provider 禁用持久化，主题操作不重置当前业务状态。

主题仅改变外观与间距，不改变记录、权限或页码。需要显式尺寸时使用当前组件公开支持的尺寸参数；48/36px 是默认/large 非虚拟表格的基础行高 token，粗指针下行高与内距均按至少 44px 的操作目标计算，纯文本短行和表头也满足该目标。`small`、`middle`、虚拟行以及宿主内联单元格样式不受这组行高规则控制；长内容应允许换行，宽表格在容器内滚动。

## 边界与性能

使用固定列时，由宿主按 AntD 实际滚动容器配置足够的 `scroll.x`，并让 AntD 自身滚动容器负责横向滚动；不要再套一层独立横向滚动容器，否则固定区可能按错误的可视边界定位。虚拟化、动态行高、合并单元格、展开与自定义 body 需单独验证。远程排序由宿主查询并避免旧响应覆盖。

## 适配层补充说明

Table 是 Ant Design 5 的薄适配层，适用于中后台的本地数据表和受控数据表。它完整透传公开 `TableProps<T>`、`TableColumnsType<T>`、分页、筛选、排序、行选择、滚动和虚拟化配置；业务请求、权限、缓存和 URL 同步由宿主处理。

## 稳定行标识

业务数据应始终提供稳定唯一的 `rowKey`（字段名或函数）。组件不会自动生成 key，也不会把数组索引当作 key。索引在插入、删除、排序或分页后会变化，可能导致选择状态和输入焦点落到错误行。

## 受控协议

`pagination`、`onChange` 和 `rowSelection` 可以由宿主受控。跨页选择由宿主结合 `preserveSelectedRowKeys` 维护；Table 不请求数据、不去重请求，也不丢弃旧响应。远程数据场景应由宿主使用 `AbortController` 或请求代次保护异步结果，并将最终 `dataSource`、分页和 loading 传给 Table。

## 固定列与虚拟化

交互示例使用 `scroll.x={856}` 保持列宽，并以单一、可聚焦的外层区域承接普通表格的横向滚动；该区域聚焦后处理无修饰的左右方向键，滚动位置在边界不变时保留浏览器默认行为。示例不启用固定列。固定列属于宿主布局决策：宿主应按真实容器宽度设置 `rowSelection.fixed`、列 `fixed` 与足够的 `scroll.x`，并由 AntD 自身滚动容器管理横向滚动；不要将固定列与普通示例的外层滚动区域混用。AntD 5.24 没有直接提供 prop/ref 配置默认固定列内部滚动区的名称、焦点或键盘行为；`onCell`、`components.body.cell` 和 `components.body` 等公开扩展点允许宿主自建交互，但不提供现成的键盘导航协议。固定列行为见下文边界说明。`scroll.y` 和 `virtual` 是显式 opt-in，虚拟表格应保持稳定行高；合并单元格、展开行、自定义 body、动态行高和拖拽列等高级组合需按 AntD 5 限制单独验证。组件不封装自定义虚拟滚动引擎或列拖拽协议。

## Ref、样式与键盘

`ref` 指向由 AntD 根入口 `Table` 组件推导出的公开实例类型（`LxTableRef`），不承诺 HTMLElement。该类型遵循 peer 依赖 `antd >=5 <6`，不会要求业务代码引入 `antd/es/*` 或 `rc-table`。组件不增加 wrapper，`className` 直接落在 AntD 根节点，以保持横向滚动、固定列和布局语义。示例在 Table 外使用可聚焦命名区域承接横向滚动；启用固定列时，宿主应由 AntD 自身的滚动容器承担横向滚动，并按该容器的真实尺寸验证固定区。基础组件不自动改变宿主的焦点顺序。主题的 light/dark 和 comfortable/compact 由 `LxConfigProvider` 的 token 运行时控制。

## 固定列的键盘边界

AntD 5.24 的固定列表格默认内部横向滚动区不是 Tab 停靠点；没有直接提供 prop/ref 为其命名、配置键盘滚动或管理焦点。宿主可以通过 `onCell`、`components.body.cell` 和 `components.body` 等公开扩展点自建交互，但需自行负责焦点和与固定列、虚拟化的协调。普通滚动区的方向键适配器不适用于固定列，本示例不通过私有 DOM 补焦点或拦截方向键。Tab 仍按顺序访问行选择框和单元格内的真实操作控件。定向浏览器测试覆盖固定列启用的 930px section 与 447/448px 最小边界，也覆盖 390/320px 关闭固定列时的采购员操作；粗指针测试还验证 448px 启用边界的按钮和焦点轮廓与固定列之间留有间距。纯文本单元格不进入 Tab 顺序，也不承诺表格网格的方向键导航。

Table 默认保留原生静态表格语义，不会把纯文本单元格变为 Tab 停靠点，也不将左右方向键用于单元格间移动。普通溢出演示区域的方向键只负责横向滚动；单元格中的交互控件保留自身键盘行为。该模型的适用范围、代价和未来网格能力的重新评估条件见 [ADR-0005](../../../../docs/adr/0005-table-keyboard-model.md)。

## 设计与验证边界

示例对应 `UI/P0 基础组件-Data Display/` 的当前组件场景，所有恢复、失败与加载操作均为本地 React 状态，不发送网络请求。基础示例供观察单组件，交互示例说明宿主受控状态与恢复协议。静态检查不能替代明暗对比度、焦点、窄屏及 reduced motion 的独立浏览器验收。
